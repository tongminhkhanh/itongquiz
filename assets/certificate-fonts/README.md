# Certificate name fonts

These TrueType files are the Vietnamese-capable Google Fonts assets used by
the certificate Worker:

- `PlaywriteVN-Regular.ttf` — Playwrite Việt Nam
- `Allura-Regular.ttf` — Allura
- `AlexBrush-Regular.ttf` — Alex Brush

They are distributed under the SIL Open Font License through Google Fonts.
Before deploying a Worker version that enables these choices, upload the files
to the `itongquiz-certificates` R2 bucket under:

```text
fonts/PlaywriteVN-Regular.ttf
fonts/Allura-Regular.ttf
fonts/AlexBrush-Regular.ttf
```

Great Vibes and Dancing Script are already part of the existing certificate
font bundle in R2.
